# AI practice files

Practice files for the AI workshop book. Everything here is fictional: the
office, its departments, staff, applicants and figures are made up, so you
can use these files with any AI tool. The survey products named in
`approved-tools.pdf` are real, but the approval decisions are invented.

## Getting the files

Click the green **Code** button above, then **Download ZIP**, and unzip it
into a new folder. Or, with git: `git clone` this repository.

Work on a copy, so you can start again if you want to.
